# Проверка AI-Rescue вместе с Cactus Client

Cactus Client — отдельный игровой клиент DDNet. Он нужен для того, чтобы ты мог зайти на сервер и наблюдать/играть рядом с AI-Rescue. Сам бот подключается к серверу как отдельный игрок; Cactus не встраивается в бота и не управляет им.

## Скачать Cactus Client

Скачивай клиент с официального сайта разработчика: https://cactuss.top/

На странице выбери Windows 64-bit (если у тебя обычная 64-разрядная Windows), скачай ZIP и распакуй его в отдельную папку. Запусти DDNet.exe из распакованной папки.

Важно: Cactus — закрытый исходный код. Поэтому этот репозиторий не хранит и не перепаковывает его исполняемые файлы. Ссылка ведёт на сайт проекта, а не на сторонний архив. Перед использованием проверь правила сервера относительно сторонних клиентов.

## Как проверить AI-Rescue

1. Запусти Cactus и подключись к нужному BLOCK-серверу (например, Multeasymap).
2. Запусти AI-Rescue отдельно по инструкции в README и укажи тот же сервер.
3. Убедись, что на сервере видны два разных игрока: твой Tee и бот.
4. Для безопасного теста сначала используй пассивный режим/остановку, затем включай бой. Не публикуй пароль приватного сервера в Issues или логах.

## Важно

- Cactus не является частью сборки AI-Rescue.
- Не помещай Cactus.exe или его DLL в этот репозиторий: клиент распространяется отдельно его разработчиком.
- Если бот не подключается, приложи лог AI-Rescue и название сервера; сам Cactus обычно не требуется для сетевого подключения бота.
